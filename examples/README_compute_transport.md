# MMCE N 实体算力传输联调

实时算力线路由以下实体方块组成：

```text
机器算力端口
-> 算力线缆
-> 有线算力接口
-> 算力线缆
-> 算力分发端点
-> 算力线缆
-> 算力矩阵端口
```

无线线路仅替换机器到接口的第一段：

```text
机器控制器
-> 无线覆盖
-> 无线算力接口
-> 算力线缆
-> 算力分发端点
-> 算力线缆
-> 算力矩阵端口
```

## 自动归属与连接顺序

1. 使用 MMCE 网络绑定器，把参与联调的 MMCE 控制器绑定到同一网络。
2. 正常成型 MMCE 机器。结构内的机器算力端口会自动归属当前机器控制器。
3. 正常成型矩阵塔。塔内的有线/无线接口、分发端点和矩阵端口会自动归属矩阵塔控制器。
4. 用算力线缆连接有线机器端口、接口、分发端点和矩阵端口。
5. 右键端点可查看自动归属的网络和控制器坐标。

自动归属只读取 MMCE 已成型结构的真实方块坐标，不会根据附近控制器猜测。控制器切换网络后，端点会同步到新网络；结构失效、控制器卸载或解绑网络后，自动归属会解除。

算力端点绑定器不再是正常机器搭建流程的必需品，仅保留给结构外独立端点和调试场景。结构内端点始终以当前 MMCE 结构控制器为准。

端点和线缆不会强制加载区块。线路所在区块卸载、控制器结构失效、端点失效或关键线缆被拆除后，对应实时算力路由停止工作。

## 路由状态

- `valid`：实体线路完整。
- `machine_endpoint_missing`：机器控制器没有已绑定的机器算力端口。
- `interface_endpoint_missing`：接口控制器没有对应的有线或无线接口。
- `distributor_endpoint_missing`：分发控制器没有算力分发端点。
- `matrix_endpoint_missing`：矩阵控制器没有算力矩阵端口。
- `wired_path_invalid`：有线链路不完整或被拆断。
- `wireless_backbone_invalid`：无线接口到分发端点或矩阵端口的后端线路不完整。
- `out_of_range`：机器控制器超出真实无线接口方块的覆盖范围。

单次路径搜索默认最多访问 8192 个已加载的线缆或端点方块，可通过 `mmcenetworks.cfg` 中的 `computeCableMaxVisitedNodes` 调整。
